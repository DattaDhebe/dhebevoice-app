# DhebeVoice

DhebeVoice is an accessible Flutter text-to-speech reader for Android and iOS. It is designed to make long-form content easier to consume by supporting text, EPUB, PDF, and readable web pages.

## Project direction

This repository sits at the intersection of **accessible application development and speech AI** in my portfolio. It complements my model-training work in [tts_humanize](https://github.com/DattaDhebe/tts_humanize) and [personal-voice-tts](https://github.com/DattaDhebe/personal-voice-tts) by focusing on the user-facing reading experience.

## Planned capabilities

- Read plain text and imported documents aloud
- Support EPUB and PDF reading workflows
- Extract readable content from web pages
- Provide playback controls and reading progress
- Keep the experience simple, accessible, and privacy-conscious

## Technology

- Flutter and Dart
- Android and iOS targets
- Platform text-to-speech capabilities

## Getting started

Install Flutter, then run:

```bash
flutter pub get
flutter run
```

For platform-specific setup, see the [Flutter documentation](https://docs.flutter.dev/get-started/install).

## Status

This project is an active application prototype. Some capabilities are still being developed; the repository should be treated as a work in progress rather than a production release.
